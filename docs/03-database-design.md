# 03 — Database Design

PostgreSQL 16 with PostGIS 3. Migrations are managed by Alembic (`backend/alembic/`).

## Conventions

- UUID primary keys (`UUIDPrimaryKeyMixin`), generated by the application.
- `created_at` / `updated_at` as `timestamptz`, stored in UTC (sessions run with `timezone=UTC`).
- Deterministic constraint names via the naming convention in `app/models/base.py`.
- Every council-owned table carries a non-null `council_id` foreign key.
- Geometry uses SRID 4326; points as `geography(Point, 4326)` for distance queries, council boundaries as `geometry(MultiPolygon, 4326)`; GiST indexes on every spatial column.
- Migrations are additive; destructive changes need a documented data-migration plan.
